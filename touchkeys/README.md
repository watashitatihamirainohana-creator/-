# touchkeys

iPad をブラウザだけで PC 音ゲー(固定鍵盤)のコントローラーにするツール。
PC 側は Python 標準ライブラリのみ、iPad 側はアプリのインストール不要。

## 使い方

1. PC(Windows)に Python 3.8 以上を入れる(インストーラーの既定のままで tkinter も入る)。
2. PC と iPad を同じ Wi-Fi につなぐ。
3. `touchkeys.pyw`(または `run.bat`)をダブルクリックする。
4. ウィンドウに出た QR コードを iPad のカメラで読み取り、Safari で開く。
5. 共有ボタン →「ホーム画面に追加」して、そのアイコンから起動する(アドレスバーや端スワイプの「戻る」が消える)。

初回は Windows ファイアウォールの許可ダイアログが出るので「プライベートネットワーク」を許可する。

ウィンドウでできること:

- **キー**: 左のレーンから順にスペース区切りで入力して「適用」。iPad 側は自動でつなぎ直して新しいレーンになる。設定は `config.json` に保存される。
- **入力モニター**: レーンごとの押下状態と押した回数を表示する。「テストモード」にすると PC にキーを送らないので、ゲームなしで連打や同時押しが届いているか確かめられる。
- **アドレスの切り替え**: PC に複数のネットワークがあるときだけ表示される。QR でつながらなければ別のアドレスを選ぶ。

## コマンドラインで使う場合

GUI なしでも動く。

```
python server.py --keys d f j k
python server.py --keys s d f space j k l
```

### オプション

| オプション | 内容 |
| --- | --- |
| `--keys` | 左のレーンから順に割り当てるキー。文字のほか `space` `enter` `shift` `ctrl` `alt` `left` `right` `up` `down` `f1`〜`f12` など |
| `--slide` | 指を滑らせて隣のレーンに入ったら押し替える(既定は最初に触れたレーンで固定) |
| `--no-retrigger` | 押さえ中のレーンを別の指で叩いても打ち直さない |
| `--retrigger-ms` | 打ち直し時の「離す→押す」の間隔(既定 8ms)。連打が抜けるゲームでは 16 などに上げる |
| `--port` | ポート番号(既定 8765) |
| `--dry-run` | キーを押さずログだけ出す(Windows 以外でも動く確認用) |

## 入力が落ちないようにしている点

- 画面全体を 1 枚のタッチ面として扱い、`click` ではなく `touchstart` / `touchend` を直接受ける。ダブルタップ判定・ズーム・スクロール・長押しメニュー・テキスト選択はすべて無効化。
- 指ごとに ID で追跡するので、同時押し・長押し・同じ場所の連打はそれぞれ独立した押下になる。
- 同じレーンを 2 本指で交互に叩くと、前の指が離れる前に次の指が着く。このとき「離す→押す」を送り直すので連打が抜けない。
- iOS が `touchend` を落とした場合や、切断・画面切り替え時は自動でキーを離す。
- PC 側は `SendInput` にスキャンコードで送るので、DirectInput / RawInput のゲームにも届く。

## iPad 側でやっておく設定

Web ページからは止められない OS のジェスチャーがある。

- **アクセスガイド**(設定 → アクセシビリティ → アクセスガイド)をオンにし、プレイ中にトップボタン(またはホームボタン)を 3 回押す。ホームへ戻るスワイプ、通知センター、コントロールセンターが止まる。これがいちばん確実。
- 設定 → マルチタスクとジェスチャ →「4本または5本指でのスワイプ」などをオフ(5 鍵以上で同時押しするとき)。
- 設定 → アクセシビリティ → タッチ →「タッチ調整」がオフになっていること。

## うまくいかないとき

- **ゲームにキーが届かない**: ゲームが管理者権限で動いている場合は、`server.py` も管理者権限のコマンドプロンプトから起動する。アンチチートが仮想入力を弾くゲームでは使えない。
- **iPad から開けない**: 同じ Wi-Fi か、ファイアウォールで Python が許可されているかを確認する。
- キー入力の注入は Windows のみ対応(macOS / Linux は `--dry-run` のみ)。
